Photo Privacy Mask Privacy Policy

Last updated: September 27, 2026

Photo masking, face and license-plate assistance, text, stickers, and background effects are processed on the user's iPhone. Photos are not uploaded to a developer server for these features.

Photo Access

Users explicitly choose photos through the iOS system photo picker. When a user saves a finished result to Photos, the app requests the permission required by iOS to add the new image. Export creates a new photo and does not overwrite the original.

Data Collection

The current version does not require an account and does not include advertising, third-party analytics, or tracking. The developer does not collect selected photos, masks, text, stickers, or edited results through a developer server.

On-device Processing

Face and license-plate assistance, masking, text, stickers, and background effects are performed using on-device capabilities. Automatic detection may miss items, so users should review the final output before sharing or publishing it.

Face Data

When a user actively selects a photo and uses face detection assistance, Photo Privacy Mask processes information about face locations on the device, such as face bounding boxes, coordinates, and positions. This information is used only to create and position privacy masks.

The app does not use Face Data to identify or verify a person's identity, does not create a face identity database or user profile, and does not use Face Data for authentication, advertising, marketing, analytics, or cross-app tracking.

Sharing and storage: Face Data is not transmitted to the developer and is not sold, rented, shared, or disclosed to third parties. Face Data is processed only on the user's device; no developer-operated server or cloud database receives or stores this data.

Retention and deletion: Face detection data is temporary data required for the photo editing session and is not permanently retained by the developer on any server. When the relevant editing session ends or the app no longer needs the data for processing, it is no longer retained for use by the app. Exported photos are stored only on the user's device/photo library at the user's direction and can be deleted by the user.

Changes

If a future version adds cloud services, analytics, advertising, or other data processing, this policy will be updated accordingly.

Contact

For questions about this privacy policy, please use the developer support contact listed on the app's App Store product page.
