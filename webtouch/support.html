技術支援

「電視牆觸控」是一款獨立開發的 iPad 電視牆觸控控制工具，透過使用者自行設定的區域網路位址，連接相容設備原有的網頁控制介面。本 App 並非設備製造商的官方軟體。

使用條件：iPadOS 17 或更新版本、能連接電視牆設備的區域網路，以及有效的設備登入權限。目前已於 DACOMS DB-6000 進行實機測試；其他廠牌或機型的網頁及手勢相容性尚未經逐一驗證。

首次使用

  1. 將 iPad 連上可以存取電視牆控制器的可信任 Wi-Fi 或區域網路。
  2. 開啟「電視牆觸控」，依設備設定輸入設備 IP、連接埠及 HTTP／HTTPS。如設備使用特定登入網頁路徑，可在進階設定中調整。
  3. 點選「儲存並連線」。下次啟動會讀取前次儲存的設備位址。
  4. 在設備原有的網頁登入畫面輸入帳號、密碼並登入。
  5. 從來源清單拖曳訊號至電視牆顯示區；以單指移動視窗，使用原廠視窗控制點調整尺寸，或雙擊進行快速吻合。

常見問題

連不上設備？ 請確認 iPad 與電視牆控制器網路互通、設備已開機、設備 IP 和連接埠正確，並允許 App 存取區域網路。此處要輸入的是電視牆設備的 IP，不是 iPad 本身的 IP。

需要外部網際網路嗎？ 控制設備所需的是可連線至設備的區域網路；實際登入及其他網路需求仍依所連接設備的網頁而定。

登入帳號或密碼不易輸入？ 請確認已點選原廠網頁內正確的輸入框，必要時重新載入頁面。登入帳密屬於設備本身，並非「電視牆觸控」App 的註冊帳號。

設備 IP 更換了怎麼辦？ 從 App 選單開啟設備設定，輸入新的設備 IP、連接埠等資訊並儲存，再重新連線。

拖曳或調整視窗不順？ 請先選取正確視窗，優先使用單指移動及原廠網頁提供的邊緣或角落控制點；實際反應也會受設備網頁、控制器及網路狀況影響。

所有電視牆設備都能使用嗎？ 不能保證。不同設備的控制網頁與協定可能不同，本 App 只對經實機確認的相容設備提供已驗證功能說明。

Technical Support

“電視牆觸控” is an independently developed touchscreen controller for iPad. It connects to the existing web control interface of compatible video-wall equipment at a local-network address provided by the user. It is not an official app from the hardware manufacturer.

Requirements: iPadOS 17 or later, local-network access to the video-wall controller, and valid credentials for that equipment. The app has been tested with a DACOMS DB-6000. Other brands and models have not been individually verified for web interface and gesture compatibility.

Getting started

  1. Connect your iPad to a trusted network that can reach the video-wall controller.
  2. Enter the device's IP address, port, and HTTP/HTTPS scheme. Adjust the login-page path under advanced settings if your equipment requires it.
  3. Tap Save and Connect. The connection settings are saved locally for next time.
  4. Sign in on the equipment's original web login page using the account provided for your device.
  5. Drag a source from the source list to the wall, move windows with one finger, resize using the device webpage's window handles, or double-tap to fit a window.

Frequently asked questions

Can't connect? Confirm that the controller is on, the iPad can reach it over the local network, the device IP and port are correct, and local-network access is permitted. Enter the controller's IP address, not the iPad's address.

Does it need internet access? Controlling the device requires a reachable local network. Other requirements depend on the device's own web control page.

Having trouble entering credentials? Make sure the actual username or password field on the device's web page is selected, and reload if necessary. These are credentials for the equipment, not a separate app account.

What if the device IP changes? Open Device Settings from the app's menu, update the address and port as needed, save, and reconnect.

Moving or resizing is inconsistent? Select the desired window first. Prefer one-finger movement and the resizing handles provided by the equipment's web page. Responsiveness depends on the device, its control interface, and the network.

Does this work with all video-wall equipment? No universal compatibility is claimed. Control interfaces and protocols vary between manufacturers and models.
